**No public explorer for this L1.** The Guardian L1 is a private Subnet-EVM chain with a local validator and no hosted
explorer, so "explorer link" evidence is replaced by **RPC receipts**: a tx hash plus the output of
`cast receipt <hash> --rpc-url $RPC` (block, status, gas, logs) and `cast tx <hash>`. Keep the RPC URL in one variable:

    export RPC=http://127.0.0.1:9650/ext/bc/4hnXBqtkcq2uj8e3rcfGKh3NDBn3CgrWPe4tk71WQFfP4rTTb/rpc
    export API=http://localhost:8000      # the l1 compose stack (make stack-l1)

Prerequisites (once): validator running, `make l1-proxy`, `Backend/.venv/bin/python infra/l1/fuji_env.py`,
`make stack-l1`, `scripts/smoke-l1.sh`, then a fresh scene-1 state with
`I_UNDERSTAND=fuji RPC_URL=$RPC infra/l1/fuji-run.sh bash infra/l1/demo-reset.sh` (API_URL=$API). Details:
`docs/DEVELOPMENT.md`, "The same stack on the Guardian L1". Test keys only; nothing here is sent to a public network
other than Fuji testnet.

## Commands per evidence

`COUNCIL_TIMELOCK_S` defaults to 15 in `infra/l1/fuji_env.py` and `infra/l1/fuji-run.sh` (the Council delay is
immutable per deployment; measured: a reset takes about 190 s at 20 s and 170 s at 15 s, D9 allows 180 s).

**D1**

    cast chain-id --rpc-url $RPC                                  # 845357
    cast block-number --rpc-url $RPC
    # roles of the two precompiles: 0 none, 1 enabled, 2 admin (after the handover the Council contract is admin)
    cast call 0x0200000000000000000000000000000000000002 'readAllowList(address)(uint256)' <COUNCIL> --rpc-url $RPC
    cast call 0x0200000000000000000000000000000000000000 'readAllowList(address)(uint256)' <COUNCIL> --rpc-url $RPC
    I_UNDERSTAND=fuji NETWORK=fuji RPC_URL=$RPC infra/l1/fuji-run.sh bash infra/l1/real-checks.sh t15
    # t15: after the handover the deployer is rejected by the node and cannot touch either list

For the rejection of an outsider show the raw message of `t15` (`cannot issue transaction from non-allow listed
address: 0x...`, no tx hash).

**D2**

    cat Backend/deployments/fuji-l1.json
    for c in registry vault council mockDex evilDex tUSDC tTKB tSCAM; do
      a=$(jq -r ".contracts.$c" Backend/deployments/fuji-l1.json); echo "$c $a $(cast codesize $a --rpc-url $RPC)"; done
    I_UNDERSTAND=fuji NETWORK=fuji RPC_URL=$RPC infra/l1/fuji-run.sh bash infra/l1/contracts.sh verify-seed
    I_UNDERSTAND=fuji NETWORK=fuji RPC_URL=$RPC infra/l1/fuji-run.sh bash infra/l1/contracts.sh verify-handover

**D3, D4, D5, D7, D10 (scenes 1-5 through the HTTP API, health to replay)**

    scripts/smoke-l1.sh                                           # health: chainMode=l1, simulated=false, lag <= 2
    # fresh state first: demo-reset (see above), then, in Backend/:
    E2E_BASE_URL=$API E2E_RPC_URL=$RPC E2E_DEPLOYMENTS_FILE=deployments/fuji-l1.json \
      uv run pytest tests/e2e -q -s -k running_stack            # the 60+ row table incl. scene 4 steps 1-5, tx hashes
    # or the CLI, which also prints the tx hash per step:
    uv run python -m tests.e2e.scene_all $API --real --rpc $RPC --council <COUNCIL> --huy <HUY>

The table has the agent swap hash (D3), the reasons of steps 1-5 with district spent 5.000 / 5.000 / 15.000 /
25.000 / 25.000 (D5; section 4.3), the scene 3 merge and scene 5 requests #12 / #13 (D7) and the API-versus-chain
reads (D10). For each hash: `cast receipt <hash> --rpc-url $RPC` and paste block, status and the `Swapped` /
`Spent` log. Scene 4 with the Council timelock (the API keeper executes the merge after the delay) is the same run;
`cd Backend && uv run python ../infra/l1/e2e_scene4.py $API` is the scene-4-only variant.

**D6 (lock)**

    I_UNDERSTAND=fuji NETWORK=fuji RPC_URL=$RPC infra/l1/fuji-run.sh bash infra/l1/real-checks.sh v2   # policy v2 (needs it before t8)
    I_UNDERSTAND=fuji NETWORK=fuji RPC_URL=$RPC infra/l1/fuji-run.sh bash infra/l1/real-checks.sh t8
    # t8: Lan calls emergencyLock(minh); the 5 keys read role 0; the node rejects their next tx with no hash
    # inside `make e2e` the same is rows "readAllowList on chain for the 5 keys" and "step 7 ... BLOCKED_AT_PROTOCOL"
    for k in <5 key addresses of minh>; do cast call 0x0200000000000000000000000000000000000002 \
      'readAllowList(address)(uint256)' $k --rpc-url $RPC; done                                      # all 0

Note: `real-checks.sh t8` locks `minh` on the live deployment; run a demo-reset afterwards (it enables the locked keys
again, D9).

**D8**

    cd contracts && forge test                                    # summary line
    gh run list --branch main --limit 3                           # CI run link; Backend: uv run pytest -q

**D9**

    time ( I_UNDERSTAND=fuji RPC_URL=$RPC API_URL=$API infra/l1/fuji-run.sh bash infra/l1/demo-reset.sh )

The script prints the duration of every phase (open, deploy, seed, switch, finish, verify) and "RESET COMPLETE".

`make e2e` ran 56 of 65 scene checks green; the 9 that differ are anvil limits (no node-level Tx AllowList, and
estimates 5.000 apart because anvil's seed is not the real Seed script), see `docs/DEVELOPMENT.md`.
